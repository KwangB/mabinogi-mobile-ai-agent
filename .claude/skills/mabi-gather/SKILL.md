# 채집 돌리기

요청: $ARGUMENTS

## 1. 이름 확정 (무료, 조회 1번)
`query(get_gatherable_items, filter:"<키워드>")`
- 정확히 하나면 그 `DisplayName`. 여러 개(양털 / 두꺼운 양털 / 황금 양털)면 어느 것인지 묻는다. 추측 금지.
- 목록에 없으면 "생활 스킬 레벨이 모자라 아직 못 캐는 것일 수 있어요"라고 알리고 멈춘다.
- `ToolOk:false` 면 도구 문제(아래 5번).

가방·잔액·도구·직전 실패는 `gather` 가 **무료로 알아서 걸러 주므로** 따로 조회하지 않는다.

## 2. 비용 고지 (한 줄)
- 1호출 = 정령의 날개 5개 = 최대 100개. 필요한 호출 수 = ⌈수량 ÷ 100⌉. 수량을 말하지 않았으면 100개(1회).
- 100개 미만이면 `stopAtCount`(실험적, 몇 개 초과 가능). "같은 5개로 100개까지 되는데 <수량>개만 할까요?"를 한 번만 묻는다.
- 예: `양털 100개 → 1회 · 정령의 날개 5개 (214 → 209)`

## 3. 실행
- `gather(displayName, stopAtCount?)` → `running` 이면 `job(action:"wait")` 를 반복. **기다리는 동안 말하지 않는다.**
- 여러 호출이 필요하면 한 호출이 끝날 때마다 결과를 말하고 계속할지 묻는다.
- "그만/멈춰" → 즉시 `stop_action`.
- 낚시 전용 항목은 `result:"started"` 로 바로 돌아오고 **스스로 끝나지 않는다.** 시작할 때 이 점을 알리고, 대화를 마칠 때 아직 켜져 있으면 상기시킨다.

## 4. 보고 (한두 줄)
`<이름> <gained>개 · 날개 <spentNow>개 사용 · 남은 날개 <balanceAfter> (날개 1개당 <perWing>개)` — `bagWarning` 이 있으면 덧붙인다. `newGatherables` 가 있으면 "새로 열린 채집물: …(생활 레벨이 오른 것 같아요)" 한 줄.

## 5. 거부·중단됐을 때 (쉬운 말로)
| 결과 | 말해 줄 것 |
|---|---|
| `bag_nearly_full` / `overweight` | 가방이 꽉 찼어요. 팔거나 보관함에 넣은 뒤 다시 말해 주세요(날개는 안 나갔어요 / 중간에 멈췄어요) |
| `tool_missing` / `tool_broken` | 쓸 도구가 없어요. 수리·구매는 직접 하셔야 해요. 팁: 싼 입문용 도구를 여러 개 가방에 넣어 두면 닳을 때 게임이 알아서 바꿔 끼워 줘요 |
| `blocked` + `kind` | 게임 화면에 확인할 창이 떠 있어요(1시간 확인 포함). 처리하고 알려 주세요 |
| `not_in_field` / `no_route` | 던전·마이홈 밖 필드로 나와 주세요 |
| `recent_failure` | 방금 같은 작업이 중단됐어요. 원인이 해결됐는지 확인받고 `retryAfterFix:true` |
| `budget_exceeded` / `daily_budget_exceeded` / `reserve_protected` | 안전장치예요. 값은 `.mcp.json` 에서 사용자만 바꿀 수 있어요 |

전체 도구 점검이 필요하면 `snapshot(sections:["gear"])` — `noUsableTool` 이 쓸 도구가 없는 채집물 목록이다.
