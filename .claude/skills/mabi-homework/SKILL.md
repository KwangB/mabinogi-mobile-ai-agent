# 숙제 (일일 · 주간)

요청: $ARGUMENTS

## 원칙
- **전리품이 남은 것만 숙제다.** 다 받은 콘텐츠는 재입장이 가능해도 완료 → 다시 돌라고 권하지 않는다.
- 초기화(매일 06:00 · 월요일 06:00 KST)와 남은 시간은 도구가 계산한다. 직접 날짜 계산을 하지 않는다.
- 전투 숙제(검은 구멍·결계·던전·필드 보스)는 사용자가 직접 하고, 너는 **기록과 알림**만 한다. 기록은 로컬 파일이라 게임에 영향이 없고 무료다.
- 어비스·레이드는 체크리스트에 없다(직접 플레이). "카브락 깼어"에는 체크하지 말고 가볍게 받아 준다. 규칙·준비를 물으면 `homework(action:"guide", item)` 결과(주간 전리품 규칙, 입장 조건과 내 전투력·마도 저항 차이)를 요약해 주고, 보스 패턴은 지어내지 않는다.

## A. "숙제 뭐 남았어?"
`homework(action:"list")` **한 번.** 결과가 이미 압축돼 있으니 거의 그대로 보여 준다.

```
🗓 <now> · 초기화까지 <reset>
✅ <done>
[일일] <left.일일>
[주간] <left.주간>
[필드 보스] <left["필드 보스"]>   ⏰ <upcoming>
[계정] <left["일일 · 계정"]> / <left["주간 · 계정"]>
🧵 가공 완료 <live.altering.readyToCollect>건 (있을 때만)
```
- 표기: `이름 3/7` = 횟수형 진행도, `⚠` = 횟수·시간표를 직접 확인하지 못한 항목, `[달걀×10]` = AI 가 채집을 도울 수 있는 재료.
- 주간 초기화가 24시간 이내면 주간을, 일일 초기화가 3시간 이내면 일일을 먼저 짚어 준다.
- `sync` 가 `ok` 가 아니면 게임이 꺼져 있는 것 → 일일/주간 미션은 직접 체크해야 한다고 한 줄.
- 설명이 필요할 때만 `detail:true`.

## B. "○○ 했어"
- `homework(action:"check", item:"<말한 이름>")` — 별칭 가능(검구, 결계, 요던, 크라마, 정기 의뢰). "3번 했어" → `count:3`, "다 했어" → `all:true`, "필보 다 돌았어" → `group:"필드 보스", all:true`.
- 여러 개를 말하면 호출을 이어서 하고, 답은 마지막에 한 줄(`summary` 의 일일 n/m · 주간 n/m). 보드를 다시 그리지 않는다.
- `candidates` → 어느 것인지 묻는다. `guide_only` → 체크하지 않는다. 잘못 체크는 `uncheck`, 값 지정은 `set`.

## C. 목록 다듬기
- 안 하는 콘텐츠 끄기 `disable` / 다시 켜기 `enable`. 묶음: `group:"preset:shop"`(주간 상점), `"preset:barter"`(물물교환), `"preset:event"`, `"preset:legacy"`, `"preset:raid-abyss"`.
- 새 항목 `add`(name, cycle, count, scope). 기본 항목은 지우지 못하고 끌 수만 있다.
- 횟수가 실제와 다르면 `data/homework.json` 의 `count` 를 고친다(사용자 승인 후). 근거는 `docs/homework.md`.

## D. 캐릭터 여러 개
- 게임은 캐릭터 이름을 알려 주지 않는다. 프로필은 사용자가 붙인 별명: `homework(action:"characters", character:"부캐")`.
- 계정 공유 항목(주간 미션, 길드 미션, 캐시샵, 성수 교환)은 프로필끼리 공유된다.
- 자동 반영은 "지금 접속한 캐릭터"의 진행도를 "선택된 프로필"에 적는다 → 프로필이 2개 이상이면 먼저 "지금 접속한 캐릭터가 <active> 맞나요?"를 확인한다.

## E. AI 가 도울 수 있는 숙제 (요청받았을 때만, 비용 고지 후)
- 자동 반영 항목: 보상 미수령이면 알려 주기(무료)
- 가공 완료품 수령 → `/mabi-craft` B
- `[재료×n]` 이 붙은 물물교환·납품 재료 채집 → `/mabi-gather` (1회 5개). 교환·수락·납품은 사용자가 직접
- "숙제 알아서 다 해 놔"는 방치형 사용이라 거절하고 위에서 가능한 것만 제안한다
