# 생활 레벨 올리기

요청: $ARGUMENTS

근거: `docs/life-skill-guide.md` — **필요한 절만** 읽는다(채집 요령 = 3절, 제작 = 4절). 품목·장소는 2025년 자료가 많으니 ⚠️ 는 "확인 필요"로 전한다.

## 제약
- 커넥터는 생활 스킬 **레벨·경험치를 알려 주지 않는다**(생활력 수치만). 올릴 스킬과 현재 레벨은 사용자에게 묻고, 레벨이 올랐는지도 사용자에게 확인을 부탁한다.
- `query(get_gatherable_items)` 에는 요구 레벨을 충족한 채집물만 나온다 → "지금 캘 수 있는 것"의 기준.
- 구매·수리·교환·아르바이트·가방 정리는 직접. 자리를 비운 채 돌리는 요청은 거절한다.

## 1. 무엇을 올릴까 (묻기 전에 제안)
- 우선순위: 나무 베기·광석 캐기·양털 깎기(시설 재료) → 약초·곤충 → 일상 채집·추수·호미질·낚시. 제작은 재료가 쌓였을 때.
- "생활력 수치"가 목표면 스킬 레벨보다 **도구 등급·가방 3개·시설 업그레이드**가 먼저라고 알려 준다.
- 생활 레벨과 시설은 계정 공유라 부캐 아르바이트도 도움이 된다.

## 2. 채집으로 올리기 — 날개 효율이 핵심
1. `query(get_gatherable_items, filter:"<키워드>")` 로 지금 캘 수 있는 것을 확인(1번).
2. **희귀 드롭을 목표로 제안한다.** `gather` 는 지정한 아이템이 100개가 될 때까지 채집하고 같은 채집지의 다른 드롭은 세지 않는다 → 돌멩이·나뭇가지·네잎클로버·황금 ○○ 를 지정하면 같은 5개로 훨씬 오래 채집한다(= 경험치가 많다). 그 이름이 조회 결과에 **실제로 있을 때만** 쓴다.
3. 커넥터는 갈 수 있는 가장 가까운 채집지를 고른다 → 요구 레벨이 높은 채집지 근처에 서 있으라고 안내한다.
4. 레벨업용이면 저렴한 입문용 도구 + 여분 여러 개가 유리하다(채집량이 적어 가방이 덜 차고, 닳으면 게임이 가방의 도구로 자동 교체).
5. 고지: `황금 양털 목표 채집 1회 · 정령의 날개 5개 · 가방이 차거나 도구가 떨어지거나 1시간 확인이 뜰 때까지 계속됩니다. 멈추려면 "그만".`
6. `gather` → `job(action:"wait")` 반복(그 사이 말하지 않는다). 가방·도구·잔액·직전 실패는 도구가 무료로 걸러 준다.
7. 끝나면: 획득 수·쓴 날개·`perWing` 을 한 줄로. 레벨이 올랐는지 물어보고, 새 채집물이 열렸는지 같은 조회를 한 번 더 한다(전에 없던 이름 = 다음 목표).

## 3. 제작으로 올리기
- `query(get_craftable_items, filter, onlyActionable:true)` → 가이드 4절 기준으로 제안: 제작 6종은 2차 가공 재료 → 상위 장비, 물약 조제는 회복 물약 → 자동 회복 물약, 요리는 삶은 달걀 → 상위 요리, 핸디크래프트는 못·캠프파이어·생활 도구.
- **`craftCount` 를 시설 상한까지 한 호출에 묶는다**(→ `/mabi-craft` A). 재료가 모자라면 `/mabi-craft` C 로 총비용부터.
- 거래 가치가 있어 보이는 재료를 태우기 전에 한 번 확인한다.

## 4. 가공 · 낚시
- 가공 등록은 1건당 5개라 비효율 → 게임에서 직접 여러 건 걸고, 수령만 맡기라고 권한다.
- 낚시는 수동이 자동보다 3~5배 빠르다. 그래도 자동 낚시를 원하면 `/mabi-gather` 의 낚시 절차.

## 마무리
오늘 한 것과 쓴 날개를 한 줄로 요약하고 다음 제안은 1~2개만. 실사용에서 확인된 사실(희귀 드롭 목표가 실제로 되는지, 몇 분 돌았는지)은 `docs/field-notes.md` 에 적는다.
