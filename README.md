# mabinogi-mobile-ai-agent — 마비노기 모바일 AI 커넥터(Beta) Claude Code 세팅

2026-09-17 에 추가된 **마비노기 모바일 AI 커넥터(Beta)** 를 Claude Code 로 쓰기 위한 프로젝트 키트. **세 가지 일(숙제 · 생활 레벨 · 채집/제작/가공)**에 집중하고, **토큰(요금)과 정령의 날개를 아끼도록** 설계했다.

| # | 목적 | 말하는 법 | 스킬 |
|---|---|---|---|
| 1 | 숙제 (일일·주간) | "숙제 뭐 남았어?" · "검은 구멍 했어" | `/mabi-homework` |
| 2 | 생활 레벨 올리기 (채집 스킬·제작 스킬·가공 시설) | "양털 깎기 올려줘" · "목공 레벨 올려줘" | `/mabi-life` |
| 3 | 특정 채집·제작·가공 돌리기 | "양털 모아줘" · "○○ 10개 만들어줘" · "타르 만들게 재료 채워 줘" · "가공 받아 와" | `/mabi-gather` · `/mabi-craft` |

처음이면 `/mabi-start`, 연결이 안 되면 `/mabi-doctor`.

> **비공식 팬 프로젝트입니다.** 넥슨·데브캣과 무관하며, 게임에 포함된 공식 CLI 를 그대로 호출할 뿐 게임·CLI 를 변조하지 않습니다. 그래도 운영정책 11조에 따라 **AI 로 한 모든 행위의 책임과 비용(AI 요금·정령의 날개)은 사용하는 본인**에게 있습니다. 베타 기능이라 언제든 바뀔 수 있고, 이 도구는 무보증(MIT)으로 제공됩니다. 서버는 네트워크에 접속하지 않으며 게임에 보낸 모든 명령을 `logs/` 에 남깁니다.

## 빠른 시작 (Windows PC)

1. 준비: 마비노기 모바일 **PC 버전**(2026-09-17 이후), [Node.js 18+](https://nodejs.org), Git for Windows, [Claude Code](https://code.claude.com/docs).
2. 받기:
   ```bash
   git clone https://github.com/KwangB/mabinogi-mobile-ai-agent.git
   ```
3. 점검(게임 없이): 폴더 안에서 `node server/test/smoke.mjs` → 마지막 줄 `37/37 passed`.
4. 게임에서 켜기: 캐릭터로 접속한 뒤 `[메뉴(≡)] → [환경 설정] → [게임] → [AI 제어] → 마비노기 모바일 AI 커넥터(Beta)` ON.
5. 이 폴더에서 `claude` 실행 → 프로젝트 MCP 서버 `mabinogi` 승인 → **`/mabi-start`**.

자세한 절차와 첫 실행 체크리스트: [docs/windows-setup.md](docs/windows-setup.md)

> ⚠️ AI 커넥터는 **Windows PC 버전 전용**이다. 2026-09-19 Windows 실제 게임에서 조회·숙제·채집 흐름을 확인했다. 숙제의 수동 기록은 게임 없이도 쓸 수 있다.

## 시작 가이드 (처음 5분)

`/mabi-start` 를 치면 연결 상태·레벨·가방·정령의 날개를 한 번에 보여 주고 메뉴 3개를 고르게 한다. 시작 화면과 1번은 전부 무료 조회이고, **2번·3번은 실제로 채집·제작을 맡기는 순간부터 한 번에 정령의 날개 5개**가 든다(고르기·비용 계산까지는 무료).

```
✅ 연결됨 · Lv.100 빙결술사 · 가방 703/1040
🪽 정령의 날개 49,950개 → 맡기기 9,990번 가능 (오늘 AI 사용 0/100 · 이번 세션 0/30)

무엇을 도와드릴까요?
1) 숙제 확인 — "숙제 뭐 남았어?"
2) 생활 레벨 올리기 — "양털 깎기 올려줘" / "목공 올려줘"
3) 채집·제작·가공 돌리기 — "양털 모아줘" / "○○ 만들어줘" / "재료 채워 줘"
```

### 1) 숙제 — 말하면 기록, 게임이 알려 주는 건 자동

- "숙제 뭐 남았어?" → 일일·주간·필드 보스·계정 단위로 **전리품이 남은 것만** 보여 준다. 일일·주간 미션과 정기 의뢰 진행도는 게임에서 자동으로 읽어 온다.
- 검은 구멍·결계·던전·어비스·레이드는 **직접 플레이**하고, 끝나면 "검구 했어", "결계 3번 했어", "카브락 깼어"라고 말하면 기록된다.
- 결계(매 정각)·필드 보스 출현 시각과 초기화(매일 06:00·월요일 06:00)까지 남은 시간도 같이 나온다.

### 2) 생활 레벨 — 채집·제작·가공 시설을 최적 목표로 골라 실행 (실행 1회 = 날개 5개)

- 범위는 채집 스킬 8종, 제작 스킬 9종, 가공 시설 레벨 전부다. 커넥터가 레벨 숫자를 주지 않으므로 "지금 열린 것"으로 구간을 추정하고 그 안에서 목표를 고른다.

- "양털 깎기 올려줘"처럼 말하면 지금 캘 수 있는 목록을 조회해 **가장 높은 단계의 희귀 드롭을 목표로 스스로 고르고**, 비용을 알린 뒤 한 번 실행한다. 조언이 아니라 실행이 결과물이다.
- 커넥터는 생활 스킬 레벨을 주지 않지만, 채집 뒤 새로 열린 채집물(`newGatherables`)로 레벨 상승을 알아채고 다음 목표를 제안한다.
- "목공 레벨 올려줘" → 만들 수 있는 제작법 중 가장 높은 티어를 고른다. 재료가 없으면 `plan_craft` 가 채집 → 가공 → 제작 순서와 비용을 표로 만들고, 승인 한 번에 순서대로 실행한다.
- 가공은 캐릭터 스킬이 아니라 **시설 레벨**이고 경험치가 없다. 업그레이드는 게임에서 직접 하고, 거기 드는 재료(부품·합금강괴·상급 목재 등)를 같은 방식으로 계획해 채집·가공해 둔다.

### 3) 채집·제작·가공 — 원하는 것을 콕 집어서 (실행 1회 = 날개 5개)

- "양털 100개 구해줘" → `양털 100개 → 1회 · 정령의 날개 5개 (49,950 → 49,945)` 라고 비용을 먼저 알려 주고, Claude Code 확인 창을 승인하면 시작한다.
- 한 번 맡길 때 5개, 수량과 무관. 양털 100개는 약 1분 40초가 걸렸다(2026-09-19 실측).
- 끝나면 한 줄로 보고한다: `양털 102개 · 날개 5개 사용 · 남은 날개 49,945 (날개 1개당 20.4개)`.
- "타르 만들게 재료 채워 줘" → `plan_craft` 가 부족 재료를 따라 내려가 `채집 통나무 35개(1회·5) → 가공 타르 1건(5)` 같은 표를 만든다. 승인 한 번에 순서대로 실행하고, 가공이 끝나는 시간(수십 분~수 시간)은 기다리지 않고 알려 준다. 가공 등록은 경험치가 없어 게임에서 직접 거는 편을 권한다(표에 아낄 수 있는 날개가 같이 나온다).

### 자주 묻는 것

| 질문 | 답 |
|---|---|
| 상태·숙제 확인에도 날개가 드나? | 아니다. 조회는 전부 무료. 날개는 2번·3번에서 채집·제작·가공을 **실제로 맡길 때만** 5개. 목표 고르기와 비용 계산까지는 무료. |
| 던전·사냥터·정기 의뢰도 돌아 주나? | 못 한다. 전투·이동·수리·거래는 게임이 AI 에 열어 두지 않았다. 남은 횟수와 재화 계산만 해 준다. |
| 그럼 뭐에 쓰나? | 던전 도는 동안 재료를 대신 모아 두거나, 생활 레벨 올릴 때 희귀 채집물을 100개씩 맡기는 용도. 채집지가 멀거나 오래 걸릴수록 값어치가 있다. |
| 밤새 돌려 달라고 하면? | 거절한다. 한 번에 처리할 분량만 하고 멈춘다(운영정책 11조·방치형 금지). |
| 가방이 꽉 찼다고 하면? | 가방 정리는 직접. 95% 이상이면 채집·제작을 시작하지 않는다(날개는 안 나간다). |

## 정령의 날개를 아끼는 장치 (전부 "돈이 나가기 전" 무료 단계에서 동작)

| 장치 | 막는 낭비 |
|---|---|
| 이름·도구·재료 사전 검증 | 잘못된 이름, 도구 없음, 재료 부족으로 실패하는 호출 |
| 가방 95% 이상이면 채집·제작 거부(80%↑ 경고) | 시작하자마자 무게 초과로 끝나는 채집·제작 |
| 직전 실패 재시도 차단(10분) | `blocked`·`tool_broken` 직후 같은 요청을 다시 해서 5개를 또 쓰는 것 |
| 세션 예산 30 · **하루 상한 100**(세션을 새로 열어도 유지) · 잔액 하한 20 | 과다 지출 |
| 지침: 채집은 한 번에 끝까지, 제작은 `craftCount` 상한까지 묶기, 가공 등록 대신 수령만 | 호출 수 자체 |
| 결과에 `perWing`(날개 1개당 획득량) | 어떤 작업이 효율적인지 보이게 |
| 채집 후 `newGatherables`(새로 열린 채집물) 자동 비교 | 레벨이 올랐는지 보려고 조회를 또 하는 것 |
| `plan_craft`: 부족 재료를 따라 내려가 채집→가공→제작 계획과 예상 날개(무료) | 재료 없는 채로 제작을 눌러 실패하거나, 단계마다 묻고 조회하는 것 |

## 토큰을 아끼는 장치

- 세션마다 고정으로 실리는 글자 수 약 22,400 → **약 11,000** (지침·서버 안내·도구 정의·스킬 설명 합계, −51%).
- 숙제 보드 출력 2,710 → **643자**. 상세가 필요할 때만 `detail:true`.
- 도구 묶음 `MABI_PROFILE=core`(11개). 채팅·연주 등은 `full` 로 바꿀 때만 실린다.
- 목록 조회(채집물·제작법·가공)는 서버가 20초 캐시한다(`MABI_LIST_CACHE_SEC`). 이름 확정·재료 계획·채집 전후 비교가 같은 목록을 다시 읽지 않고, 비용이 나가는 활동이 끝나면 비운다. 원본(`compact:false`) 조회에도 `limit` 이 적용된다(제작 목록은 1,800행·21만 자).
- 긴 채집은 270초 단위로 기다린다(프롬프트 캐시가 식지 않는 간격). 기다리는 동안 에이전트는 말하지 않는다.
- **가장 큰 절약은 모델 선택이다.** 숙제 체크·채집 같은 일상 작업은 Sonnet 이나 Haiku 로 충분하다(세션에서 모델을 바꾸거나 `.claude/settings.json` 에 `"model"` 지정).

## 설정값 (`.mcp.json` → `env`) — 바꾼 뒤 Claude Code 재시작

| 변수 | 이 프로젝트 | 설명 |
|---|---|---|
| `MABI_PROFILE` | core | `full` = 채팅·연주·일어서기·신규 명령 호출 도구까지 노출 |
| `MABI_WINGS_SESSION_BUDGET` | 30 | 한 세션에서 AI 가 쓸 수 있는 정령의 날개(= 맡기기 6번) |
| `MABI_WINGS_DAILY_BUDGET` | 100 | 하루(06:00 KST 기준) 상한. 0 = 끔 |
| `MABI_WINGS_RESERVE` | 20 | 잔액이 이 아래로 내려가는 활동은 거부 |
| `MABI_BAG_REFUSE_PERCENT` / `MABI_BAG_WARN_PERCENT` | 95 / 80 | 가방 점검 기준 |
| `MABI_RETRY_GUARD_SEC` | 600 | 실패 직후 재시도 차단 시간 |
| `MABI_MAX_WAIT_SEC` | 270 | 도구 호출 1회가 기다리는 최대 시간(넘으면 `job` 핸들) |
| `MABI_LIST_CACHE_SEC` | 20 | 채집물·제작법·가공 목록 캐시(초). 0 = 끔 |
| `MABI_ACTION_TIMEOUT_SEC` | 3600 | 활동 1건의 최대 시간(희귀 드롭 목표 채집은 오래 걸린다) |
| `MABINOGI_CLI_PATH` | 자동 | 게임을 기본 경로가 아닌 곳에 설치했을 때 |
| `MABI_BODY_ENCODING` | auto | 한글 이름이 계속 not_found 면 `raw`/`base64` 고정 |
| `MABI_LOG` / `MABI_LOG_DIR` | on / `logs/` | 게임에 보낸 모든 명령의 감사 로그 |

보호 장치 값은 **사용자만** 바꾼다(에이전트는 바꾸지 않도록 지침에 명시).

## 선택 기능 켜기

1. `.mcp.json` 의 `MABI_PROFILE` 을 `full` 로.
2. `extras/skills/` 에서 필요한 폴더를 `.claude/skills/` 로 복사: `mabi-music`(연주), `mabi-raid-guide`(어비스·레이드 가이드), `mabi-guild-request`(정기 의뢰 재화 점검), `mabi-gearcheck`(도구 점검), `mabi-plan`·`mabi-alter`·`mabi-briefing`(단독판).
   - 어비스·레이드 안내와 도구 점검은 핵심 도구만으로도 된다(`homework` 의 guide, `snapshot` 의 gear). 스킬은 절차를 더 자세히 적어 둔 것이다.

## 하지 않는 것 (의도적)

- 무인 반복·방치형 자동화, 전투 자동화(던전·어비스·레이드, 패턴 회피), 수리하러 가기 — 커넥터에 명령이 없고, 화면 제어·매크로 우회는 운영정책 11조 위반·계정 제재 대상이다.
- 게임/CLI 파일 수정, 거래소·캐시샵·길드 운영·1:1 대화 흉내.

## 알아 둘 한계

- 실제 게임 검증은 2026-09-19 Lv.100 캐릭터 한 명으로 `status`·`snapshot`·`homework`·`gather` 만 확인했다. 제작·가공·낚시·희귀 드롭 채집은 아직 실측하지 않았다. 실사용에서 확인한 사실은 `docs/field-notes.md` 에 적는다(개인 메모라 레포에 포함하지 않는다).
- 숙제·생활 가이드의 ⚠️ 항목은 2025년 자료이거나 횟수를 확인하지 못했다.
- 베타 기능이라 패치로 바뀔 수 있다. `status` 가 명령 변동을 알려 준다.
