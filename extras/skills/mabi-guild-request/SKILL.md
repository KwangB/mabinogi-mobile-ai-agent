# 모험가 길드의 정기 의뢰 (주간 · 재화 소모 관리)

요청: $ARGUMENTS

## 알아 둘 것
- 주간 퀘스트(월요일 06:00 초기화). 목표는 **심층 던전 / 던전 / 사냥터** 클리어 횟수이고 게임은 위에 적힌 목표부터 자동 진행한다. 횟수·보상은 바뀔 수 있으니 **게임이 준 목표(`steps`)가 기준**이다.
- 핵심 보상은 주간 첫 완료(미스틱 다이스 + 공명의 도안 2개). 에반이 찾아와 주므로 **던전·어비스·레이드 밖에서 에반과 대화해야 완료**된다. 2회차부터는 3만 골드 수준 → 첫 완료를 끝냈으면 숙제는 완료로 보고 더 돌라고 권하지 않는다.
- 전투 콘텐츠라 **직접 돈다.** 입장·난이도·더블 루팅 설정도 사용자가 게임에서 한다. 너는 진행도·재화·순서만 챙긴다.
- 드는 재화: 던전·사냥터 임무 = **은동전 10개**(더블 루팅 20개), 심층 어려움 = **마족 공물 1개**(매우 어려움 2개, 더블 루팅 불가), 임무 없이 입장하는 [자동 재도전] = **정령의 날개 3개/회**(AI 맡기기와 같은 지갑). 더블 루팅과 자동 재도전은 동시에 쓸 수 없다.
- 충전: 은동전 30분에 1개(보유 100개 미만일 때만), 마족 공물 12시간에 1개(Lv.55부터, 보유 10개 미만일 때만). 클리어 전 퇴장하면 전액 환급.

## A. 진행도 + 재화 — `homework(action:"plan")` 한 번 (무료)

```
📜 <questTitle> · 주간 초기화 <weeklyReset>
1) 심층 던전 1/3 → 2회 남음 · <where> <difficulty> · 마족 공물 <need> 필요 / <have> 보유 → <short>개 부족 ❗
2) 던전 5/5 ✅
3) 사냥터 0/5 → 5회 남음 · <where> · 더블 루팅 · 은동전 <need> 필요 / <have> 보유 → 충분
💰 은동전 <n> · 마족 공물 <n> · 정령의 날개 <n>
```
- `spend` 가 있으면 그 숫자를 그대로 쓴다: `runs`(돌아야 할 판 수 — 던전은 더블 루팅 1판이 2회로 세어진다고 보고 계산), `need`/`have`/`short`, `recoverIn`(부족분이 자동 회복되는 데 걸리는 시간). 직접 계산하지 않는다.
- 입장 화면의 비용이 설정값(은동전 10 · 공물 1)과 다르다고 하면 `data/homework.json` 의 `costPerRun` 을 고친다(승인 후).
- `levelTooLow` → 그 장소는 아직 못 간다. 입장 가능한 곳으로 설정을 바꾸자고 제안한다(E).
- 재화가 부족하면: 더블 루팅을 끄면 절반이 든다는 점, 임무를 선택하지 않고 입장하면 은동전·공물 없이도 돌 수 있다는 점(보상 구조는 다름)을 알려 준다.
- `source:"fallback"` → 실제 진행도를 못 읽은 것. `hint` 를 전하고 횟수는 "예전 자료 기준"이라고 밝힌다.
- `allDone:true` → "이번 주 정기 의뢰 끝"이라고만 말하고 `homework(action:"check", item:"정기 의뢰", all:true)`.

## B. 돌기 전 점검 (원할 때만, 무료)
`snapshot(sections:["me"])` — 포만감, 가방 무게(80% 이상이면 경고: 전리품이 쌓인다). 물약·음식 재고가 궁금하면 `query(get_items, filter:"물약")`. 부족한 것은 알려 주기만 한다.

## C. 같이 챙길 숙제
`homework(action:"list", cycle:"weekly")` 에서 같은 판으로 채워질 만한 것(심층 던전 숙제, 같은 지역의 필드 보스·검은 구멍·결계)을 한 줄로 짚어 준다. 확실하지 않은 것은 "~일 수 있어요"로 말하고 다음 `plan` 으로 확인한다.

## D. 도는 중 / 끝난 뒤
- 사용자가 물을 때만 `plan` 을 다시 조회한다. 혼자 주기적으로 확인하지 않는다.
- 더블 루팅 1판이 2회로 세어진다는 것은 나무위키 기준(던전)이다. 사냥터는 언급이 없어 1회로 계산해 뒀다 → 첫 판 뒤의 진행도로 확인해 다르면 `doubleLootCountsTwice` 를 고치고 `docs/field-notes.md` 에 적는다.

## E. 설정 바꾸기
"사냥터는 ○○로", "심층은 매우 어려움으로", "더블 루팅 꺼줘" → `data/homework.json` 의 `guild_weekly_request.plan.objectives` 에서 해당 줄의 `where`·`difficulty`·`doubleLoot`·`costPerRun`·`minLevel` 을 고친다(바꿀 내용을 한 줄로 보여 주고 확인받은 뒤). 고친 다음 `plan` 으로 확인.

현재 설정(2026-09-19): 심층 = 페카 고분 심층 · 어려움(Lv.95 해금 — 입장 레벨이 100인 심층은 없다) / 던전 = 피오드 던전(일반 Lv.93·95, 어려움 Lv.100) · 더블 루팅 / 사냥터 = 창백한 산(일반·어려움) · 더블 루팅.
초보 캐릭터라 이 장소에 못 가면, 갈 수 있는 가장 높은 던전·사냥터로 바꾸고 더블 루팅은 은동전이 넉넉할 때만 켠다.
