## 체크리스트에서 뺀 것 — 어비스 · 레이드 (직접 플레이 가이드)

사용자 결정(2026-09-19): 어비스·레이드는 사람이 직접 하는 콘텐츠이므로 숙제 체크리스트에 넣지 않고 **가이드**로 안내한다. 데이터는 `data/homework.json` 의 `guides`, 조회는 `homework(action:"guide")` / `/mabi-raid-guide`.

| 콘텐츠 | 주간 전리품 | 근거 |
|---|---|---|
| 어비스(룬다: 허상의 정박지 / 광기의 동굴 / 흩어진 물길) | 클리어 전리품 주 3회까지, 월 06시 초기화. 이후 반복은 하트 토큰·골드·증표 소량 | 공식 가이드(2026-07-02), 9/17 업데이트 노트(지옥3 추가 9/21 오픈, 지옥2 마도 저항 6,000) |
| 레이드(카브락 / 화이트 서큐버스 / 에이렐) | 보스별 주 1회(난이도 무관), 월 06시 초기화 | 공식 가이드(2026-09-17), 9/17 노트(에이렐 매우 어려움 9/21 오픈: 필요 전투력 88,500 · 마도 저항 3,000) |
| 타바르타스 · 뱅가드 브리치 ⚠️ | 커뮤니티 트래커에만 있음(규칙 미확인) | mabimobi.life |

가이드가 주는 것: 전리품 규칙과 초기화까지 남은 시간, 입장 조건, 난이도별 필요 전투력·마도 저항과 **내 수치의 차이**, 패치 변경점, 준비물 점검, 내 공략 메모(`docs/guides/`). 보스 패턴 공략은 데이터에 없다 — 요청하면 웹에서 찾아 출처와 함께 메모 파일에 정리한다.
다시 체크리스트로 관리하고 싶으면 `homework(action:"enable", group:"preset:raid-abyss")`.

## 꺼져 있는 묶음(preset)

- `preset:raid-abyss` — 어비스 3구역, 레이드 4종, 뱅가드 브리치(위 설명 참고)
- `preset:shop` — 여관(하트 토큰 → 성수 20·음식류), 성당 성수(1,500G×5), 강화 비약 유화제(라사·스튜어트 각 10), 데카 원석 상자(증표 300, 3곳×3), 길드 상점 룬의 파편(10), 발터 데코 제작 부품류(25/16/7), 도나 성수 묶음 상자, 갈빈 튼튼한 밧줄
- `preset:barter` — 알리사(달걀 10), 케이틴 통밀빵(우유 10), 말콤(거미줄 5 / 양털 50), 퍼거스(장비 부품), 트레이시(통나무). `materials` 가 있는 항목은 AI 가 재료 채집을 도울 수 있다(교환은 직접)
- `preset:event` — 주말에는 어비스/레이드, 아르바이트(주간 멤버십)
- `preset:legacy` — 망령의 탑(5), 사냥터 구역 보스, 필드 보스 페리·크라브바흐, 어비스 네 번째 관문

물물교환·주간 상점의 전체 목록(100여 종)은 모빈포 숙제 페이지에 있다. 필요한 것만 `add` 로 추가하는 편이 보드가 가볍다.

## AI 커넥터로 되는 것 / 안 되는 것

| | 가능 여부 |
|---|---|
| 일일·주간 미션, 정기 의뢰 진행도 읽기 | ✅ 자동 동기화 |
| 가공 완료품 수령·등록, 물물교환/납품용 재료 채집 | ✅ (등록·채집은 1회당 정령의 날개 5) |
| 입장 전 상태·재화·소모품 점검 | ✅ 무료 |
| 검은 구멍·결계·던전·필드 보스·어비스·레이드 **진행, 패턴 회피, 자동 전투** | ❌ 명령 자체가 없음 + 공식 금지("성장과 관련된 자동 플레이") |
| NPC 교환·임무 수락/납품·캐시샵·거래소·길드 | ❌ 직접 |
