# 시작 (초보자용)

1. `status` 한 번. 연결이 안 되면 `hint` 를 쉬운 말로 전하고 멈춘다(자세한 진단은 `/mabi-doctor`).
2. `snapshot(sections:["me","currencies"])` 한 번. 여기서 가방 무게(`me.Vitals`)와 정령의 날개를 읽는다.
3. 아래 형식으로 **짧게** 보여 주고 고르게 한다. 다른 조회는 하지 않는다.

```
✅ 연결됨 · Lv.<레벨> <직업> · 가방 <현재>/<최대>
🪽 정령의 날개 <N>개 → 맡기기 <N÷5 내림>번 가능 (오늘 AI 사용 <today> · 이번 세션 <session>)

무엇을 도와드릴까요?
1) 숙제 확인 — "숙제 뭐 남았어?"
2) 생활 레벨 올리기 — "나무 베기 올리고 싶어"
3) 채집·제작 돌리기 — "양털 모아줘" / "○○ 만들어줘"
```

- 가방이 80% 이상이면 "채집 전에 가방부터 비우면 날개를 덜 낭비해요" 한 줄.
- 날개가 25개 미만이면 "오늘은 조회와 숙제 확인 위주로 쓰는 게 좋아요" 한 줄.
- 처음 쓰는 사용자 같으면 덧붙인다: 조회는 공짜, 채집·제작은 한 번 맡길 때마다 정령의 날개 5개, 매번 확인 창이 뜬다, 1시간마다 게임 화면에서 확인을 눌러야 한다, 전투·수리·거래는 직접 해야 한다.
