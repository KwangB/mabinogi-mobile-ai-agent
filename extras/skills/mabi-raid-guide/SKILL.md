# 어비스 · 레이드 가이드 (직접 플레이)

요청: $ARGUMENTS

## 원칙

- 어비스·레이드는 **사람이 직접 하는 콘텐츠**다. 사용자 결정(2026-09-19)에 따라 숙제 체크리스트에서 뺐고, 여기서는 가이드만 준다. "카브락 깼어" 같은 말에는 축하 한마디면 충분하고 체크하지 않는다(`homework` 가 `guide_only` 를 돌려준다). 사용자가 체크리스트로 관리하고 싶다고 하면 `homework(action:"enable", group:"preset:raid-abyss")`.
- 입장·전투·패턴 회피·스킬 사용을 자동화하지 않는다. 커넥터에 그런 명령이 없고 공식 금지 영역이며, 화면 인식·매크로는 계정 제재 대상이고 파티원에게 피해를 준다.
- **보스 패턴·공략을 지어내지 않는다.** 이 저장소에 있는 것은 공식 가이드·패치 노트의 규칙과 수치뿐이다.

## 절차

1. `homework(action:"guide", item:"<어비스|레이드|보스 이름>")` — 한 번에 온다(무료):
   - `loot`: 주간 전리품 규칙, `weeklyReset`: 초기화까지 남은 시간
   - `entry` / `structure` / `tips`: 입장 조건, 구성, 패치 변경점
   - `requirements[]`: 난이도별 필요 전투력·마도 저항과 **내 수치와의 차이**(`combatScoreGap`, `arcaneResistanceGap`, `meets`). 게임이 꺼져 있으면 비교 없이 규칙만.
2. 출력 예:
   ```
   ⚔️ 레이드 — 클리어 전리품은 보스별 주 1회 · 초기화 09-21(월) 06:00 (45시간 뒤)
   내 스펙: 전투력 45,210 · 마도 저항 3,200
   · 에이렐 매우 어려움: 필요 88,500 / 마도 저항 3,000 → 전투력 43,290 부족 ❌ (9/21 06시 오픈)
   입장: 레벨 65 + 선행 퀘스트 · 부활 제한(어려움 함께 5 / 혼자 3)
   참고: 지난 시즌 룬의 유일 효과는 적용되지 않음
   ```
   - 데이터에 없는 난이도는 "수치가 없다"고 말하고, 게임의 입장 화면에서 필요/권장 전투력을 확인하라고 안내한다. 사용자가 알려 주면 `data/homework.json` 의 `guides[].requirements` 에 추가한다(승인 후).
3. **준비물 점검**(원하면, 무료): `snapshot(sections:["me","activity"])` 로 체력·포만감·가방 무게, `query(get_items, filter:"물약")` / `query(get_items, category:"Food")` 로 소모품 재고. 부족한 것은 알려 주기만 한다.
4. **공략 메모**: `guides[].notesFile`(`docs/guides/abyss-notes.md`, `docs/guides/raid-notes.md`)에 사용자가 적어 둔 메모가 있으면 입장 전에 요약해 준다. 비어 있으면 "패턴 공략을 찾아서 정리해 둘까요?"라고 묻는다 → 승인하면 웹에서 찾아 **출처와 함께 자기 말로 요약**해 그 파일에 기록한다(긴 인용 금지, 확인 안 된 내용은 그렇게 표시).
5. 전리품을 이미 받은 보스·구역은 다시 가라고 권하지 않는다(전리품 남은 것만 의미가 있다). 이 정보는 커넥터로 알 수 없으므로 사용자 말에 따른다.
