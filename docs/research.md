## 공식적으로 확인된 사실

**무엇인가** — 사용자가 쓰던 AI 도구와 게임 클라이언트를 잇는 "다리". 게임이 AI 를 제공하는 것이 아니며, 게임 쪽 구성 요소는 클라이언트에 포함되어 있어 별도 설치가 없다.

**지원 도구** — Claude Code, Cursor, Gemini CLI / Antigravity, Windsurf, Cline / Roo Code, Kiro, OpenCode + "동일한 표준 규격을 지원하는 도구". PC 에 설치된 도구를 게임이 자동 인식해 연결 방법을 등록한다. 도구가 하나도 없으면 토글을 켜도 동작하지 않는다.

**켜는 법** — PC 버전 `[메뉴(≡)] → [환경 설정] → [게임] → [AI 제어] → [마비노기 모바일 AI 커넥터(Beta)]` 토글 → 이용 확인 팝업에서 체크 후 [활성화]. 기본 OFF. **활성화 후 7일간 미사용 시 자동 OFF.** PC 버전 전용(모바일은 기술적 방법 모색 중).

**할 수 있는 것**
- 물어보기(무료): 캐릭터 상태·능력치, 위치·날씨·에린 시각, 재화·가방 무게, 퀘스트, 일일/주간 미션, 주변 NPC·플레이어, 재료·악보·악기 목록
- 맡기기: 채집(낚시터 자동 낚시 시작 포함), 가공 등록·진행 확인·수령, 제작, 연주·악기 교체, 행동 중단·일어서기, 채팅(승인제)

**방치형 방지 장치**
- 활동 1회당 **정령의 날개 5개**(조회는 무료). 부족하면 실행되지 않는다. AI 도구가 소모 전 사용자에게 확인할 수 있다.
- **1시간 연속 사용 시 확인 팝업** — 사용자가 확인해야 이후 요청이 처리된다.
- 접속 중에만 동작. 로그인/캐릭터 선택 화면에서는 처리하지 않으며 대신 접속하지 않는다.

**채팅** — 일반 채팅 작성 가능하나 사용자 확인 없이는 전송되지 않는다. AI 가 쓴 채팅에는 캐릭터 이름 옆 AI 아이콘 표시. 도배·불쾌감 유발은 채팅 이용 제한.

**할 수 없는 것** — 거래소 등록·구매 / 성장 관련 자동 플레이 / 결제·캐시샵 / 길드 운영(추방·임명 등) / 1:1 대화 전송 / 아이템 버리기·분해 / 외부 메신저·SNS 연동. "되돌릴 수 없거나, 재산에 영향을 주거나, 다른 모험가에게 직접 영향을 미치는 행동은 직접" — 기능이 확장돼도 유지할 원칙.

**개인정보** — 캐릭터 이름, 길드명, 채팅 내용은 AI 도구로 전달되지 않는다. 같은 파티/길드 여부 같은 관계 정보만 이름 없이 전달.

**비용·책임** — AI 도구 이용 요금(토큰)은 사용자와 AI 제공사 간의 문제이며 게임이 부담하지 않는다. 채집·제작처럼 오래 걸리는 활동을 반복해 맡길수록 사용량이 늘어난다. 미성년자는 법정 대리인 동의가 필요할 수 있다.

**운영정책 11조** — [11-1-1] AI 에이전트로 수행한 모든 행위와 결과의 책임은 고객 본인. [11-1-2] 외부 AI 서비스 비용은 고객 부담. [11-2] **회사가 허용하지 않은 방식으로 기능을 변조해서는 안 되며**, 기능 변조·게임 및 타인의 이용 방해가 확인되면 이용 제한.

**같은 업데이트의 편의 개선**(커넥터와 무관하게) — 채집물 탐색 기본 목표 10 → 100, 던전 자동 재도전(1회당 정령의 날개 3개), 어비스 다시 하기.

## 커뮤니티 기술 자료로 파악한 것 (미검증 — 실사용 시 확인 필요)

- 실체는 `C:\Nexon\MabinogiMobile\MabinogiMobile_CLI.exe`. 1회성 CLI 이며 실행 중인 게임과 named pipe 로 통신. 명령 28개. → `docs/cli-reference.md`
- 정책상 금지 영역은 명령 자체가 없다(인터페이스 수준 강제).
- 한글 본문은 `base64:<UTF-8 본문의 base64>` 형식 지원(셸 경유 시 깨짐 방지). 셸 없이 프로세스를 직접 띄우면 원문도 동작한다는 보고.
- 조사 시점(9/18) 한 사용자 환경에서는 토글을 켜도 `~/.claude.json` 에 MCP 서버가 등록되지 않았다고 한다. 게임이 Claude Code 에 정확히 무엇을 등록하는지는 **확인하지 못했다.**
- 미확인: 연주의 정령의 날개 소모 여부(카탈로그엔 표기 없음 / 공식 가이드는 "활동"으로 분류), 채팅 승인이 게임 팝업으로도 뜨는지, 1시간 팝업이 CLI 응답에 어떻게 나타나는지(`blocked`+`kind` 로 추정).

## 이 세팅의 설계 판단

| 판단 | 이유 |
|---|---|
| 공식 CLI 를 그대로 호출하는 **MCP 래퍼** | 한글·JSON 인자의 셸 인용 문제 제거, 도구 단위 권한 제어, 출력 압축(토큰 절약). CLI·게임은 일절 변조하지 않음 |
| 비용 활동·채팅은 권한 `ask` 고정 | "소모 전 확인", "채팅은 반드시 확인"이라는 공식 취지를 Claude Code 의 확인 창으로 구현 |
| 예산·하한을 **코드**로 강제 | 프롬프트만으로는 실수를 막을 수 없는 "돈이 나가는" 부분 |
| 무인 반복 기능을 만들지 않음 | 방치형 방지 취지·운영정책과 충돌. 커뮤니티의 "무한 자동 루틴"류는 의도적으로 제외 |
| 감사 로그(JSONL) | 책임이 사용자에게 있으므로 AI 가 무엇을 했는지 추적 가능해야 함 |
| 봉투/인코딩을 관대하게 처리 | 직접 검증할 수 없는 부분(이 Mac 에서는 게임 실행 불가)에서 첫 실행 실패를 줄이기 위함 |
