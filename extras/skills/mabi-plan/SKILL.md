# 재료 계획 (실행 없음 · 비용 없음)

목표: $ARGUMENTS

## 절차

1. **목표 확정** — `query(get_craftable_items, filter)` → 없으면 `query(get_alterable_items, filter)`. 정확한 `DisplayName`, `ProducedPerCraft`/`ProducedPerWork`, `MissingIngredients` 확보.
   - 필요한 제작 횟수 = ⌈목표 개수 ÷ 1회 생산량⌉.
   - `MissingIngredients` 의 `Required` 는 **1회 기준일 수 있다.** 여러 회를 만들 계획이면 단정하지 말고 "1회 기준 필요량 × 횟수"로 계산했다는 가정을 표에 명시한다.
2. **부족 재료마다 출처 확인** (각각 무료 조회, 반드시 `filter` 사용)
   - 보유량 재확인: `query(get_items, filter:"<재료명>")` — 가방 + 보관함(`Location`) 합산.
   - 만들 수 있나: `get_craftable_items` → `get_alterable_items`
   - 캘 수 있나: `get_gatherable_items` (`ToolOk` 확인). 목록에 없으면 "현재 생활 스킬로는 채집 불가이거나 다른 경로(사냥·구매 등)로 얻는 재료"라고만 적는다. **드롭처·시세 등 커넥터가 주지 않는 정보는 지어내지 않는다.**
3. 2단계 깊이까지만 내려간다(재료의 재료). 더 깊으면 "여기서부터는 별도 계획 필요"로 끊는다. 조회가 12회를 넘어가면 중간 결과를 보여 주고 계속할지 묻는다(토큰 절약).

## 출력

```
🎯 목표: <DisplayName> × <개수>  (제작 <횟수>회, 1회당 <생산량>개)

| 재료 | 필요 | 보유 | 부족 | 확보 방법 | 호출 수 |
|---|---|---|---|---|---|
| 가는 실 | 50 | 12 | 38 | 가공(1건당 5개) → 8건 | 8 |
| 양털 | 80 | 100 | 0 | — | 0 |

🪽 예상 비용: 채집 <a>회 + 가공 <b>건 + 제작 <c>회 = <a+b+c>호출 × 5 = 정령의 날개 <합계>개
   현재 <잔액>개 · 세션 예산 남음 <n>개 → <가능/부족>
⏱ 가공은 대기 시간이 있어 한 번에 끝나지 않을 수 있음
🚫 직접 하셔야 하는 것: <도구 구매/수리, 가방 정리, 스킬 레벨, 시설 레벨 등>
```

## 마무리

- "이 계획대로 진행할까요? 1단계(<첫 작업>)부터 시작합니다." 라고 **묻고 멈춘다.**
- 승인받으면 단계별로 `/mabi-gather` → `/mabi-alter` → `/mabi-craft` 절차를 따르되, **단계가 끝날 때마다 결과를 보고하고 다음 단계 진행을 확인**받는다(계획 승인 ≠ 무인 연속 실행).
