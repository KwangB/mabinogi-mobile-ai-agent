# 도구 · 악기 내구도 점검

요청: $ARGUMENTS

## 할 수 있는 것과 없는 것

| | 가능 여부 |
|---|---|
| 쓸 수 있는 도구가 없는 채집물 찾기(`ToolOk:false`) | ✅ 무료 |
| 악기 내구도 확인 | ✅ 무료 |
| 채집 도중 도구가 부서진 것 감지(`tool_broken`) | ✅ |
| 여분 도구 **제작** 제안(제작 레시피가 있을 때) | ✅ 호출당 정령의 날개 5 |
| **수리하러 이동 / 수리 / 도구 구매 / 장착 변경** | ❌ 커넥터에 명령이 없다 |
| 무기·방어구 내구도 조회 | ❌ 제공되지 않는다 |

"수리하러 가 줘"라는 요청에는: 커넥터에 이동·NPC 대화·수리 명령이 없어 불가능하다고 설명한다. **화면 제어·매크로·키 입력 같은 다른 수단으로 게임 창을 조작해 대신하지 않는다**(운영정책상 비인가 자동화, 계정 제재 위험). 넥슨이 수리 명령을 추가하면 `status` 의 `newCommands` 에 나타나므로 그때 다시 검토한다.

## 절차

1. `snapshot(sections:["gear"])`
   - `gear.gatherables.noUsableTool`: 쓸 도구가 하나도 없는 채집물(도구가 없거나 가방의 여분까지 전부 내구도 0).
   - `gear.instruments`: 악기별 `Durability`, `low:true` 는 10 이하.
2. 특정 채집물만 볼 때는 `query(get_gatherable_items, filter:"<이름>")` 의 `ToolOk`.
3. 결과를 짧게 보고:
   ```
   🛠 채집 가능 <toolOk>/<total> · 도구 없음: 철광석, …
   🎻 악기: 류트 50 · 만돌린 8 ⚠️
   ```

## 도구가 없거나 부서졌을 때의 대안 (공식 기능 안에서)

1. **여분 도구 전략(권장):** 게임은 도구 내구도가 다 닳으면 가방의 다른 도구로 **자동 교체**한다. 저렴한 입문용 도구를 종류별로 넉넉히 사 두고(도구 가방에 넣으면 무게 0) 돌리면 수리하러 갈 일이 크게 준다. 구매는 사용자가 직접(대장간·잡화점).
2. **제작:** 그 도구가 핸디크래프트 등으로 제작 가능하면 `query(get_craftable_items, filter:"<도구 이름>")` 로 확인하고 `/mabi-craft` 절차로 제안한다. 도구 이름을 모르면 사용자에게 묻는다(추측 금지). 만든 도구가 자동으로 장착되는지는 게임 동작에 달려 있으니, 제작 후 `ToolOk` 를 다시 조회해 확인한다.
3. **수리:** 사용자가 NPC 에서 직접. 수리가 끝났다고 하면 `ToolOk` 를 다시 확인한 뒤 작업을 재개한다.

## 채집 중 `tool_broken` 이 났을 때

- 획득량과 이미 나간 날개(`wings.spentNow`)를 보고한다.
- **같은 요청을 바로 재시도하지 않는다**(날개만 또 나간다). 위 대안 중 하나가 해결된 뒤, `ToolOk:true` 를 확인하고 재개한다.
- 오래 돌리는 레벨업 세션이면 시작 전에 이 점검을 먼저 하도록 습관화한다(`/mabi-life` 2단계).
