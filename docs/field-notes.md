# 실사용 기록장

실제 게임에서 확인한 사실을 날짜와 함께 적는다(에이전트도 여기에 추가한다). 문서·추정과 다른 점이 나오면 이 파일이 우선한다.

형식: `- YYYY-MM-DD · <확인한 것> · <근거(도구 결과 요약)>`

## 확인 대기 (docs/windows-setup.md 6절)

- [ ] capabilities 개수 / 변동
- [ ] 한글 본문 인코딩(raw / base64)
- [ ] 활동 1회당 실제 지출
- [ ] stopAtCount 동작과 초과 개수
- [ ] 연주의 정령의 날개 소모 여부
- [ ] 채팅 승인 팝업 형태
- [ ] 1시간 확인 팝업의 CLI 응답(kind)
- [ ] 게임이 Claude Code 에 자동 등록하는 항목
- [ ] 희귀 드롭(돌멩이·황금 ○○ 등)이 `get_gatherable_items` 에 나오고 `gather` 목표로 쓸 수 있는가, 한 번에 몇 분 도는가(게임 쪽 시간 제한)
- [ ] 도구 내구도가 0이 되면 가방의 여분 도구로 자동 교체되어 채집이 이어지는가(`tool_broken` 없이)
- [ ] 제작한 도구가 자동 장착되는가(`ToolOk` 재조회)
- [ ] 가공 등록·수령이 어느 생활 스킬 경험치로 들어가는가
- [ ] 더블 루팅 1회가 정기 의뢰 횟수 2회로 세어지는가 / 입장 레벨 100 심층 던전의 정확한 이름
